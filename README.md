# THE GRAND SANCTUARY (Opening Site)

無駄を極め、贅を尽くした——**アルティメット・プレステージ・オープニングサイト**。

ミニマルだったオープニングサイトを、最先端の Web フロントエンド技術（Canvas パーティクル、Web Audio API サウンドシンセシス、3D パララックスチルト、ゴールドシマーエフェクト、紙吹雪バースト）を注ぎ込み、**「無駄に豪華」** な極上の VIP 体験サイトへと昇華させました。

外部ライブラリ（Three.js や GSAP など）や外部音声ファイル（MP3/WAV など）は一切使わず、**純粋な HTML / CSS / JavaScript のみ** で完全自己完結・超高速に動作します。

---

## ⚜ 無駄に豪華な機能一覧

1. **シネマティック・イントロダクション**
   - ページ読み込み時に、映画館の暗幕のように上下の黒帯（レターボックス）が優雅に開き、神々しいメインカードが現れます。
2. **黄金スターダスト・パーティクルシステム (HTML5 Canvas)**
   - 画面全体をゆらめく 24K ゴールド〜シャンパンゴールドの金粉星屑パーティクル。
   - マウスカーソルを近づけると優雅に揺らぎ反発するインタラクティブ制御。
3. **ホログラフィック 3D チルトカード & 光沢グレア**
   - マウスの動きに合わせてガラス調の VIP カードがリアルタイムに 3D 傾斜。
   - カード表面には動的な反射ハイライト（グレア）が走り、本物の VIP ゴールドカードのような質感を実現。
4. **Web Audio API によるリアルタイム・シンセシス音響**
   - 外部音声ファイルを一切読み込むことなく、ブラウザの音響オシレーター回路で重厚なオーケストラ風アンビエント和音（Eb Major 9th）とクリスタル・チャイムを自動合成。
   - 右上のサウンドボタン（イコライザー波形アニメーション付き）でいつでも ON/OFF 可能。
5. **シャンパン・ゴールド紙吹雪バースト**
   - 「祝杯を挙げる (CELEBRATE)」ボタンを押すと、金箔・コイン・ダイヤモンドが 3D 回転しながら盛大に宙を舞う極上演出。
6. **無駄なステータスカウンター**
   - 「ラグジュアリー指数」が起動時に 0 から 99,999% まで高速カウントアップ。
   - 「実用性: 0.00%」「PRESTIGE STATUS: ∞ MAX」の威厳ある表示。
7. **聖域の扉 (SANCTUARY GATE)**
   - 「聖域の扉を開く」ボタンを押すと、クリスタルサウンドと共に光の領域が展開。
8. **完全レスポンシブ & アクセシビリティ配慮**
   - スマートフォン（縦画面）でも崩れず、完璧なプロポーションを維持。
   - OS の「視覚効果を減らす（prefers-reduced-motion）」設定時にはアニメーションを抑制。

## 起動・閲覧方法

Node.js やビルドツールなどの事前準備は一切不要です。

### 方法 1: ブラウザで直接開く（最速）
1. エクスプローラーで本フォルダ（`opening-site`）を開きます。
2. `index.html` をダブルクリックするか、ブラウザ（Chrome, Edge, Safari など）にドラッグ＆ドロップします。

### 方法 2: ローカルHTTPサーバーで起動する
```bash
# Python を使う場合
python -m http.server 8000
```
起動後、ブラウザで [http://localhost:8000](http://localhost:8000) を開きます。

## インタラクション・楽しみ方

- **マウスを動かす**: 背景の星屑がゆらめき、VIPカードが立体的に傾き、カーソルから金色の粒子がこぼれ落ちます。
- **右上「SOUND」をクリック**: 重厚で神々しいアンビエント和音が空間を満たします。
- **「祝杯を挙げる」をクリック**: クリスタルベルの音と共に、黄金の紙吹雪が画面いっぱいに炸裂します。
- **「聖域の扉を開く」をクリック**: 荘厳な音と共に聖域オーバーレイが開きます。
