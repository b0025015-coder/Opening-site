# Opening Site

オープニングメッセージのみを画面中央に美しく表示する、シンプルで洗練されたWebサイトです。

余白を広く取ったミニマルなデザイン、上質なタイポグラフィ、そして滑らかなフェードインアニメーションを備えています。

---

## 特徴

- **ミニマル & 洗練されたデザイン**: 深みのあるダークパレットと、厳選されたフォントによる上品な佇まい。
- **滑らかなフェードイン**: 画面読み込み時に要素が段階的に浮かび上がるアニメーション演出。
- **完全レスポンシブ**: スマートフォンからデスクトップまで、画面サイズに合わせて美しく表示。
- **軽量 & 依存関係なし**: 外部ライブラリを一切使わず、純粋な HTML / CSS / JavaScript のみで構成。
- **アクセシビリティ配慮**: OSの「視覚効果を減らす（prefers-reduced-motion）」設定に対応。

## 起動・閲覧方法

Node.js やビルドツールなどのインストールは不要です。以下のいずれかの方法で閲覧できます。

### 方法 1: ブラウザで直接開く（一番簡単）

1. エクスプローラーで本フォルダ（`opening-site`）を開きます。
2. `index.html` をダブルクリックするか、お好みのWebブラウザ（Chrome, Edge, Safari など）へドラッグ＆ドロップします。

### 方法 2: ローカルHTTPサーバーで起動する（推奨）

ローカルサーバー経由で確認したい場合は、ターミナルで本ディレクトリに移動し、以下のいずれかを実行してください。

#### Python を使う場合
```bash
python -m http.server 8000
```
実行後、ブラウザで [http://localhost:8000](http://localhost:8000) にアクセスします。

#### Node.js (`npx serve`) を使う場合
```bash
npx serve .
```

#### VS Code を使う場合
- 拡張機能「Live Server」をインストールし、`index.html` を右クリックして「Open with Live Server」を選択します。
